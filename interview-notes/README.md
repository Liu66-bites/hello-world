# 编程八股文笔记

面试高频题整理，每题给出「答案要点」，适合面试前快速过一遍。

## 目录

| 方向 | 文件 | 内容 |
| --- | --- | --- |
| Java 后端 | [java.md](java.md) | Java 基础、集合、JVM、并发、Spring |
| 计算机基础 | [cs-basics.md](cs-basics.md) | 操作系统、计算机网络、数据结构与算法 |
| 数据库 / 中间件 | [database-middleware.md](database-middleware.md) | MySQL、Redis、消息队列 |
| 前端 | [frontend.md](frontend.md) | JavaScript、浏览器、CSS、Vue / React |

## 使用建议

1. 先看题目，自己试着口述答案，再对照要点。
2. 答题结构：**是什么 → 为什么 → 怎么做 / 原理 → 优缺点 / 场景**。
3. 八股文只是敲门砖，最好结合自己的项目经历讲出实际应用。

- [fe-interview](https://github.com/haizlin/fe-interview)：前端面试每日 3+1 题
- [javascript-questions](https://github.com/lydiahallie/javascript-questions)：JS 代码输出题（有中文翻译）
